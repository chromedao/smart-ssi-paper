# Smart-SSI roadmap

Public board: **[Smart-SSI project](https://github.com/orgs/chromedao/projects/3)** · Site: [chromedao.xyz/smart-ssi](https://www.chromedao.xyz/smart-ssi)

Roadmap tickets and the code live in **[chromedao/smart-ssi](https://github.com/chromedao/smart-ssi)**: each phase is a milestone, each roadmap item an issue, and the engineering work sits under it as sub-issues. This repository holds the white paper only.

Deployment follows four phases from the [white paper](README.md#roadmap-and-limits). The DAO approves each phase before the next one starts.

| Phase | Board | Milestone | Scope |
| --- | --- | --- | --- |
| 1 · Proof of concept | Now | [Phase 1](https://github.com/chromedao/smart-ssi/milestone/1) | DID on Solana, a first source (GitHub) proven through our own TLSNotary notary (open source, no external provider), first attestations for DAO members, iOS and Android apps in closed testing |
| 2 · Internal uses | Next | [Phase 2](https://github.com/chromedao/smart-ssi/milestone/2) | Anti-sybil voting, proof-gated Metaverse access, 5 to 10 sources |
| 3 · Opening up | Later | [Phase 3](https://github.com/chromedao/smart-ssi/milestone/3) | Public SDK for verifiers, first paying partners, full security audit, legal review |
| 4 · Decentralization | Later | [Phase 4](https://github.com/chromedao/smart-ssi/milestone/4) | Independent attestor network, interpretation in a TEE, interop with the EU wallet |

Later means later: not a promise, not a date.
